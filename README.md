# 借景明心 · 八相心园

一款女性向 3D 国风心理治愈网页游戏。苏州园林美学 × 五志归脏 × 八字命局 × PAD 情绪测评。

## 玩法链路

```
生辰八字 → PAD 三维情绪测评 → 今日心色（八相择色）→ 造园闯关（八相独立场景）→ 园林画卷 → 心理评估与今日三件事
```

## 核心设计

**五志归脏**：今日心色 → 五行属性 → 归脏（肝/心/脾/肺/肾）→ 情志（怒/喜/思/悲/恐）→ 对照八字命局虚实 → 给出补母/泄子的调法。

**八相独立场景**：

| 相 | 情绪 | 场景 | 关卡 |
|---|---|---|---|
| 漏窗·囚澜 | 焦虑 | 冰裂漏窗 + 墙上狂乱树影 | 框景 → 理水 |
| 枕流·听雨 | 悲伤 | 雨丝落水自生涟漪 | 理水 → 听雨 |
| 扫竹·清暑 | 愤怒 | 竹林可真实折倒 | 扫竹 → 理水 |
| 月洞·拨云 | 迷茫 | 月洞门呼吸微光 | 拨云 → 聚焦 |
| 承晖·摇影 | 喜悦 | 墙上金斑游移 | 承光 → 理水 |
| 寄畅·绝尘 | 宁静 | 枯山水白沙纹 | 调息 → 理水 |
| 寻芳·留春 | 期待 | 寒梅 + 半透露珠 | 留春 → 拨云 |
| 立峰·骨挺 | 笃定 | 散石可叠成峰 | 叠石 → 承光 |

**技术栈**：Three.js r160（本地引用）+ 自写 GLSL + Canvas 2D + Web Audio API（古琴/滴水全程序化合成，无音频文件）。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

## 部署

静态站点，任意静态托管均可：

- **Vercel**：把本文件夹拖到 [vercel.com/new](https://vercel.com/new)
- **GitHub Pages**：推送后在 Settings → Pages 选择分支根目录
- **Netlify**：拖到 [app.netlify.com/drop](https://app.netlify.com/drop)
